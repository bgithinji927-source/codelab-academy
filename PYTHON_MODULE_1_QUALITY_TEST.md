# Lesson 1: Introduction to Python and Running Python

## Part 1 of 4: Introduction and Foundations

### What is Python?

**Python is a general-purpose programming language**. A programming language gives us a way to write instructions that a computer can interpret and execute. Python is called *general-purpose* because it is useful in many areas: web applications, automation, data analysis, artificial intelligence, testing, education, and command-line tools.

Python is designed to be readable. Compare this instruction:

```python
print("Hello, Python!")
```

The line is close to ordinary English: call `print` and give it the message `Hello, Python!`. Readability does not mean that Python is only for beginners. The same language is used to build production systems, scientific tools, and services. It means that the language tries to make the program's intention visible.

### Why Python matters

A program is useful when it can receive information, process it, and produce a result. Python provides the building blocks for all three steps:

- **Input:** data typed by a user, read from a file, received from a web service, or generated by another program.
- **Processing:** calculations, decisions, repetition, text manipulation, and data transformation.
- **Output:** text on a screen, a saved file, a web response, a report, or a change in a database.

For example, a school-fee program could receive a student's course and payment, calculate the remaining balance, and display a receipt. Python does not automatically know what the program should do; the developer expresses those rules in Python code.

### Important terminology

| Term | Meaning |
|---|---|
| **Source code** | Instructions written by a developer in a programming language. |
| **Program** | A set of instructions that can be run to perform a task. |
| **Interpreter** | Software that reads Python code and carries out its instructions. |
| **Runtime** | The period when a program is executing. |
| **Bug** | A mistake that causes a program to behave incorrectly or unexpectedly. |
| **Syntax** | The rules for writing valid Python code. |

A beginner misunderstanding is that Python "understands" an entire program like a person. It does not. Python follows precise rules. If a quote is missing or a name is misspelled, the interpreter cannot reliably determine what the instruction means and reports an error.

> **Key idea:** Learning Python is learning how to express a problem as precise, ordered instructions.

## Part 2 of 4: Detailed Concepts and Explanations

### How the Python interpreter works

When you run a Python file, the operating system starts the Python interpreter and gives it the file. The interpreter reads the source code, checks that it can be understood, and executes the instructions. If Python finds a syntax error, it stops before it can execute the affected program.

A Python file normally ends with `.py`. For example, `greeting.py` is a Python source file. The extension helps people and tools recognise the file type; the extension alone does not make invalid text into a working program.

### `print()` and function calls

A **function** is a reusable operation. `print()` is a built-in Python function that sends values to standard output, normally the terminal.

```python
print("First line")
print("Second line")
```

The parentheses contain the value passed to the function. Python executes the first call, writes `First line`, moves to the next statement, and writes `Second line`.

Expected output:

```text
First line
Second line
```

Quotation marks make the message a **string**, which means text. The quotation marks are part of the Python syntax; they are not displayed as part of the message.

### Comments and indentation

A comment begins with `#`. Python ignores the comment when it runs the file, but comments can explain an intention to another developer.

```python
# Display the first message in the program.
print("Welcome")
```

Indentation becomes important when Python code belongs to a function, loop, or condition. Although the first lesson does not yet use those structures, learners should begin forming the habit of using consistent spaces and keeping code readable.

### Common beginner mistakes

1. **Using smart quotation marks:** `print(“Hello”)` may look correct in a word processor but is not the same as normal Python quotes. Type code in a code editor.
2. **Forgetting a closing quote:** `print("Hello)` produces a `SyntaxError` because Python is still looking for the end of the string.
3. **Running from the wrong folder:** `python hello.py` only works when the terminal is in the folder containing `hello.py`, unless you provide a path.
4. **Confusing the interpreter with the editor:** VS Code or IDLE helps you write code; Python is the software that executes it.

# Lesson 2: Variables and Data Types

## Part 1 of 4: Introduction and Foundations

### What is a variable?

A **variable is a name that refers to a value**. Programs need variables because they must remember information while they work. A learner's name, a product price, and the number of completed lessons are all values a program may need later.

```python
student_name = "Amina"
```

This statement assigns the text `Amina` to the name `student_name`. The `=` symbol is the **assignment operator**. In Python, assignment means “evaluate the value on the right and associate it with the name on the left.” It does not mean that the two sides are being compared.

Variables make programs changeable. Instead of repeating `Amina` in many places, a program can use `student_name`. If the learner changes, one assignment can provide the new value to every later operation that uses the variable.

### Why data types matter

A **data type** describes what kind of value a variable refers to. The type affects which operations make sense:

- Text can be formatted and joined.
- Integers can be counted and used in whole-number calculations.
- Floats can represent measurements and prices.
- Booleans represent a true-or-false state.

The value `21` is a number, while `"21"` is text containing two characters. They look similar on the screen, but Python treats them differently.

### Terminology

- **Name:** the identifier used to refer to a value, such as `age`.
- **Value:** the data currently associated with a name.
- **Assignment:** storing or associating a value with a name.
- **Reassignment:** assigning a new value to an existing name.
- **Type:** the category of a value, such as `str` or `int`.
- **Expression:** code that Python evaluates to produce a value.

## Part 2 of 4: Detailed Concepts and Explanations

### Naming rules and conventions

A Python name may contain letters, digits, and underscores, but it cannot begin with a digit or contain spaces.

```python
learner_name = "Amina"   # valid
lesson_count = 4          # valid
# 2nd_attempt = True      # invalid: begins with a digit
# learner name = "Amina"  # invalid: contains a space
```

Python names are **case-sensitive**. `score`, `Score`, and `SCORE` are three different names. In beginner and professional Python code, descriptive names using lowercase words separated by underscores are common.

Do not use Python keywords such as `if`, `class`, or `return` as variable names. Also avoid replacing useful built-in names such as `list` or `str`.

### Core data types

| Type | Example | Typical use |
|---|---|---|
| `str` | `"Amina"` | Names, messages, addresses |
| `int` | `21` | Counts, ages, whole-number quantities |
| `float` | `1500.50` | Prices, measurements, percentages |
| `bool` | `True` | Conditions and yes/no state |

Use `type()` when you need to inspect a value:

```python
name = "Amina"
age = 21
fee = 1500.50
registered = True

print(type(name))
print(type(age))
print(type(fee))
print(type(registered))
```

Expected output:

```text
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```

The `type()` function does not change a value; it reports the type Python is already using.

### Reassignment and expressions

```python
completed = 3
completed = completed + 1
print(completed)
```

Python first stores `3`. On the second line it reads the current value, adds `1`, and stores the result back under `completed`. The output is `4`.

The right side of an assignment is evaluated before the assignment happens. That is why `completed = completed + 1` works even though the same name appears on both sides.

### Input and conversion

`input()` always returns text:

```python
age_text = input("How old are you? ")
age = int(age_text)
print(age + 1)
```

If the learner enters `20`, `age_text` is the string `"20"`. `int()` converts compatible text into the integer `20`. Without conversion, `age_text + 1` would fail because Python cannot add a number to text.

A conversion can also fail:

```python
age = int("twenty")  # ValueError
```

The error is useful information: the input does not represent a valid integer. Later lessons will teach how to handle such failures safely.

# Lesson 3: Strings and Text

## Part 1 of 4: Introduction and Foundations

A **string** is a sequence of characters used to represent text. Names, sentences, email addresses, phone numbers, and file paths can all be strings.

```python
name = "Amina"
message = "Welcome to Python"
```

Quotation marks tell Python where the text begins and ends. Single and double quotes both create strings:

```python
first = 'Amina'
second = "Amina"
```

A string containing digits is still text:

```python
phone_number = "0712345678"
```

This is intentional because phone numbers are labels, not quantities to add. A leading zero could be lost if the value were treated as a number.

Strings are important because almost every useful program communicates with people or exchanges text with another system. A registration form cleans names, a search tool compares words, and a report formats messages for a reader.

### Important terminology

- **Character:** one item in a string, such as `P`.
- **Index:** a position used to access a character; Python starts at `0`.
- **Slice:** a portion of a string selected by a start and end position.
- **Concatenation:** joining strings together.
- **Method:** an operation provided by a value, such as `.upper()`.
- **Immutable:** a string cannot be changed in place; operations produce a new string.

## Part 2 of 4: Detailed Concepts and Explanations

### Indexing

```python
word = "PYTHON"
print(word[0])
print(word[1])
print(word[-1])
```

Expected output:

```text
P
Y
N
```

The first character is at index `0`, not `1`. Negative indexes count from the end, so `-1` means the last character.

Trying to access an index that does not exist raises `IndexError`. The string `PYTHON` has six characters, so valid positive indexes are `0` through `5`.

### Slicing

A slice uses `text[start:end]`. The start is included and the end is excluded:

```python
word = "PYTHON"
print(word[0:2])
print(word[2:])
print(word[:4])
```

Expected output:

```text
PY
THON
PYTH
```

This “include the start, exclude the end” rule makes slices work predictably when they are placed next to each other.

### Length and methods

`len()` counts characters, including spaces:

```python
message = "Hello Python"
print(len(message))
```

Expected output:

```text
12
```

Common methods return a new string:

```python
raw_name = "   amina   "
print(raw_name.strip().title())
print("python".upper())
print("I like Java".replace("Java", "Python"))
```

Expected output:

```text
Amina
PYTHON
I like Python
```

Strings are immutable. `replace()` does not alter the original string; it creates and returns a new one. If the new value matters later, assign it:

```python
message = "I like Java"
message = message.replace("Java", "Python")
```

### Formatting text with f-strings

An f-string begins with `f` before the opening quote:

```python
name = "Amina"
lessons = 3
print(f"{name} has completed {lessons} lessons.")
```

Expected output:

```text
Amina has completed 3 lessons.
```

F-strings are usually clearer than manually joining many pieces. A common mistake is trying to concatenate text and a number directly:

```python
# This raises TypeError:
# "Lessons: " + lessons
```

Use an f-string or explicitly convert the number with `str(lessons)`.

# Lesson 4: Numbers and Operators

## Part 1 of 4: Introduction and Foundations

Programs use numbers to count, measure, compare, calculate prices, track progress, and model real-world quantities. Python mainly distinguishes between **integers** and **floating-point numbers**.

- An **integer (`int`)** is a whole number such as `0`, `21`, or `-4`.
- A **float (`float`)** represents a number with a decimal component such as `2.5` or `1500.75`.

```python
students = 42
price = 1500.75
```

An operator tells Python how to combine or compare values. Arithmetic operators include addition, subtraction, multiplication, and division. Comparison operators produce `True` or `False`, which later allows a program to make decisions.

### Real-world applications

A shopping program multiplies price by quantity. A progress tracker divides completed work by total work. A billing program uses comparisons to choose a rate. A game uses arithmetic to update a score or position.

The same symbol can have an important rule that beginners must learn. `/` performs regular division and produces a float, while `//` performs floor division. `%` produces a remainder, which is useful for checking whether a number is even.

## Part 2 of 4: Detailed Concepts and Explanations

### Arithmetic operators

| Operator | Meaning | Example | Result |
|---|---|---|---|
| `+` | Addition | `7 + 3` | `10` |
| `-` | Subtraction | `7 - 3` | `4` |
| `*` | Multiplication | `7 * 3` | `21` |
| `/` | Division | `7 / 3` | `2.333...` |
| `//` | Floor division | `7 // 3` | `2` |
| `%` | Remainder | `7 % 3` | `1` |
| `**` | Exponentiation | `2 ** 3` | `8` |

```python
price = 500
quantity = 4
total = price * quantity
print(total)
```

Expected output:

```text
2000
```

The expression `price * quantity` is evaluated first, then the result is assigned to `total`.

### Comparisons and Boolean results

```python
score = 75
print(score >= 50)
print(score == 100)
print(score != 0)
```

Expected output:

```text
True
False
True
```

`=` assigns; `==` compares. Confusing these symbols is one of the most common beginner mistakes.

### Logical operators

- `and` is true only when both conditions are true.
- `or` is true when at least one condition is true.
- `not` reverses a Boolean result.

```python
age = 22
has_id = True
print(age >= 18 and has_id)
```

Both conditions are true, so the result is `True`.

### Precedence

Python evaluates parentheses first, then exponentiation, multiplication/division/remainder, and addition/subtraction. Use parentheses when they make the intended rule clearer:

```python
print(10 + 5 * 2)      # 20
print((10 + 5) * 2)    # 30
```

The first result is `20` because multiplication happens before addition. The parentheses in the second expression force addition first.

# Lesson 5: Conditional Statements

## Part 1 of 4: Introduction and Foundations

A **conditional statement** lets a program choose what to do based on a condition. The condition is an expression that evaluates to either `True` or `False`.

Programs need decisions because the correct action often depends on the situation. A login program must distinguish valid credentials from invalid ones. A grading program must place marks into the correct range. A shop must decide whether a customer qualifies for a discount.

The simplest conditional is `if`:

```python
age = 20

if age >= 18:
    print("Adult access allowed")
```

Python evaluates `age >= 18`. Because the result is `True`, it executes the indented statement. If the result were `False`, Python would skip that statement.

### Important terminology

- **Condition:** an expression that produces `True` or `False`.
- **Branch:** one possible path through a decision.
- **Boolean:** a value that is either `True` or `False`.
- **Block:** a group of statements controlled by a structure.
- **Indentation:** spaces at the beginning of a line that show which block it belongs to.
- **Validation:** checking whether input meets required rules.

The colon after a condition is required. Indentation is not decoration in Python; it defines the block.

## Part 2 of 4: Detailed Concepts and Explanations

### `if`, `else`, and `elif`

Use `else` for the alternative when the `if` condition is false:

```python
age = 16

if age >= 18:
    print("Adult")
else:
    print("Minor")
```

Use `elif` to test another condition:

```python
marks = 75

if marks >= 80:
    grade = "A"
elif marks >= 70:
    grade = "B"
elif marks >= 60:
    grade = "C"
else:
    grade = "Needs improvement"

print(grade)
```

Python checks the branches from top to bottom and executes the first branch whose condition is true. This means order matters. A broad condition placed first can prevent a later, more specific condition from being reached.

### Combining conditions

```python
age = 22
has_id = True

if age >= 18 and has_id:
    print("Access granted")
```

`and` requires both conditions. `or` requires at least one condition. `not` reverses a result:

```python
has_email = False
print(not has_email)  # True
```

### Nested conditions

A nested condition is a decision inside another decision:

```python
age = 22
has_id = True

if age >= 18:
    if has_id:
        print("Entry allowed")
    else:
        print("Identification required")
else:
    print("Entry is restricted")
```

Nesting can express dependent decisions, but too much nesting can make a program hard to read. When several conditions become complicated, clear helper functions or carefully named Boolean variables can improve readability.

### Common mistakes

1. **Using `=` instead of `==`:** assignment changes a value; comparison checks a relationship.
2. **Forgetting the colon:** `if age >= 18` must end with `:`.
3. **Incorrect indentation:** statements in the same block should line up.
4. **Wrong branch order:** test specific or high-priority cases before broad fallback cases.
5. **Unvalidated ranges:** a grade program should reject marks below `0` or above `100` before assigning a grade.

### Build a grading program

```python
marks = float(input("Enter marks from 0 to 100: "))

    print("Invalid marks")

    print("Grade: A")
elif marks >= 70:
    print("Grade: B")

    print("Grade: C")

    print("Grade: E")
```

Run:

```bash
python grading.py
```

Example output for `75`:

```text
Enter marks from 0 to 100: 75

```

Python first checks whether the value is outside the valid range. If it is valid, it tests the grade boundaries from highest to lowest. The `75` is not at least `80`, but it is at least `70`, so Python selects `Grade: B` and stops checking the remaining branches.
